# ADR-0001: ForgeKit 工程基础原则

- 状态：Accepted（已确认原则；具体工具待后续 ADR）
- 日期：2026-11-15
- 标题（EN）：Engineering foundations and documentation strategy

## 背景

ForgeKit 是独立于 SiteForge 的新开发平台，目标包含跨端项目创建、资产复用、构建与发布。长期可维护性与跨模块独立演进是首要约束。

## 决策

1. Web 前端方向为 Vue 3 + TypeScript；具体框架与工具待验证。
2. 采用成熟稳定方案与模块化、低耦合架构，不为复用而过度抽象。
3. 通用 UI 组件拟通过独立 `yk-forge-ui` 仓库管理；业务模块不强制上移。
4. 混合资产体系：通用运行时包 + 可定制业务源码。
5. 功能分支、PR、CI 与审查为默认交付方式。
6. 当前简体中文文档优先，正式对外发布前提供中英文关键文档；保持翻译状态透明。
7. SiteForge 仅作为设计参考，新平台独立演进。

## 后果

有助于保持边界清晰和开发效率，但需要维护接口契约、版本兼容性及后续文档翻译。具体选型、拆仓和 CI 检查应由后续 ADR 明确。
