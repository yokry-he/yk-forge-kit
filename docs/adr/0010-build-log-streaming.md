# ADR-0010：构建日志 SSE 与控制台页面

- 状态：Accepted（B10 指定范围）
- 日期：2026-11-19
- English title: Build log streaming and console pages

## 决策

沿用 ADR-0007/0008/0009 的 MySQL 日志、OIDC 成员权限及隔离 Runner。原规格的 0009 已用于 B09，本项顺延 0010。

1. 原生 EventSource 不能携带自定义 Bearer 请求头。OIDC 客户端先以 Bearer POST 换取 32 随机字节、43 字符 base64url 票据。Redis 7 以 SHA-256 摘要为键保存身份、项目、构建与截止时间，TTL 60 秒，GETDEL 原子消费一次，可跨 API 副本使用。票据期限同时限制连接寿命。票据不进入持久浏览器状态，不输出原始异常；流入口在校验前遮蔽请求 URL 中的票据，代理/访问日志也必须删除查询参数。票据仅代表已认证身份，握手和连接期间继续查询项目成员权限。
2. 每连接从 MySQL 按 seq 升序、每批最多 500 块回放，空闲约 500ms 轮询；不引入进程内消息或 Redis pub/sub。MySQL 是唯一权威，任何 API 副本都可续传，不会出现订阅与回放之间的消息丢失；Worker 已 await 日志入库，无须改发布端。代价是每个活跃连接的轮询/授权查询压力和约 500ms 延迟。未来可用 pub/sub 唤醒轮询，但不能跳过持久化续读。
3. 观察终态后捕获日志最高序号 H，只发送该快照剩余块，再发 status/end 并关闭。B09 允许终态后追加系统日志，因此 end 只保证此快照完整；用户刷新日志可继续读取。Last-Event-ID 优先于 after，只有 log 帧携带 id。
4. 每 API 进程最多 100 个连接、同一身份最多 4 个（local 共享 4 个）。连接最长 60 秒、最多 10000 个 log 帧；最多缓存一批和一个 socket 写入，write 返回 false 时等待 drain，5 秒未恢复则断开。断连/停机释放监听器、计时器及配额。每 15 秒心跳，持续回放时也定期复核权限；空闲轮询同时复核权限。跨副本总配额由网关按身份/IP 限制，这里的限额保护单进程。
5. 控制台业务组件保留在 console，不新增生产 UI/SSE 依赖。客户端校验所有响应，按序补齐缺口，最多五次退避重试，明确 401 清会话；网络错误不退出。日志按文本插值输出，增量剥离 ANSI/控制字符；最近 5000 块/2 MiB 显示上限不替代 Worker 存储限制。清理历史日志时不得复用序号，现阶段不自动删除日志。

## 依赖评估

- `@vue/test-utils` 2.4.6：Vue 官方的 Vue 3 测试工具，MIT，维护中的 2.x，兼容现有 Vue 3.5/Vitest 3；[官方指南](https://test-utils.vuejs.org/guide/)。
- `jsdom` 26.1.0：MIT，成熟 DOM 模拟，仅开发依赖，Node >=18，兼容仓库 Node >=22。固定 26.x 避免较新版提高 Node 次版本要求；[发布记录](https://github.com/jsdom/jsdom/releases/tag/26.1.0)。无真实布局，滚动测试显式模拟属性；浏览器验收不能由 jsdom 替代。
- `ioredis` 5.11.1：MIT，复用 BullMQ 已锁定的同版本客户端，提升为 API 显式依赖，避免第二套 Redis 实现；[官方仓库](https://github.com/redis/ioredis)。支持 Redis 7 GETDEL、TLS、命令超时；有限重试/禁离线队列，异常只转换为固定中文 503。替换成本限于票据适配器。

新增测试依赖扩大开发依赖树，升级需复跑 Node 22 编译、组件测试和 Redis 集成；无需新增安装脚本授权。锁文件固定精确传递依赖；没有因本项顺带升级 ORM。

## 风险、验证与回退

HTTP 测试覆盖票据、授权、续传和终态关闭，pump 测试覆盖分批/实时/心跳/背压/清理/配额，集成测试使用专用回环 MySQL/Redis。真实 Docker 和真实 IdP/浏览器验证分别报告，不能从 mock 推断已完成。

回退 console/API 应用即可；无 schema 迁移，Redis 票据 60 秒自然失效，保留构建和日志。反向代理须禁缓冲/缓存并允许长连接；停用流入口不影响 REST 日志。中文权威，英文尚未翻译，公开发布前补齐关键指南。
