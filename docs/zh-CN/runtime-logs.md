# 已部署站点运行日志（B15）

已通过 SSH 部署并验证域名的静态站点，可以在控制台“域名与 HTTPS → 查看运行日志”选择“主机 / 站点”和来源，在线查看最近日志并实时跟随。owner、editor、viewer 均可查看；需要 OIDC 登录及本项目成员权限，本机匿名模式不可用。

## 先启用主机日志

沿用 [B13 主机准备](./domain-https.md)与 [B12 SSH 部署](./ssh-deploy.md)：专用部署用户、Python 3、Caddy 2.10.2、GNU timeout 与可信核对的 SSH 主机公钥。不需要 sudo 权限或安装日志代理，不会自动信任网络扫描得到的公钥。

升级 B15 前由运维显式执行数据库迁移 `0014_b15_runtime_logs.sql`，应用启动不会自动迁移。新绑定验证成功时自动启用按站点隔离的日志；已有 B13 绑定需点击一次“刷新证书状态”并成功，或重新“验证并启用 HTTPS”，以更新该 Caddy 实例配置。刷新不强制续签。

固定日志位于 `<部署基础目录>/.forgekit-caddy/logs/<域名绑定 UUID>/`：

| 来源 ID | 文件 | 内容 |
| --- | --- | --- |
| `caddy-access` | `access.jsonl` | 该域名 HTTP/HTTPS 请求访问日志 |
| `caddy-error` | `error.jsonl` | 该域名请求处理错误，包含 DEBUG 级 4xx 诊断 |

TLS、ACME、Caddy 启动等实例日志不会作为某个项目的日志返回。未知域名请求不写入这些来源。每文件 16 MiB 滚动、最多 3 个备份/7 天，由主机 Caddy 管理。原始文件仍在主机；控制台脱敏不会修改它们。管理员应限制访问、保护备份，并按需调整主机整体磁盘保留政策。域名移除不会自动删除主机日志。

## 使用与筛选

1. 选择主机/站点、访问或请求错误日志。
2. 默认取最近 200 行，可设 1–1000 行。
3. 可选择精确级别、最近 5/15/60 分钟起的时间窗口，以及最多 200 字符、区分大小写的关键词子串。
4. 点击“开始查看”，先显示最近行，再实时跟随。可关闭自动滚动、点击“停止跟随”；离开页面也会停止。
5. 每次会话最长 60 秒；到期或断连后，点击“开始查看”继续。网络重连只回放原会话缓冲，不自动开启新的 SSH 读取。

筛选在“最近行数”之后应用，不会扫描历史文件来补足匹配行。时间起点固定在会话启动时，之后继续接收实时日志。缺少有效 JSON level/ts 的文本在启用对应筛选时不会显示；不筛选时可查看普通完整文本行。关键词按字面值匹配，`.*`、括号或 shell 字符都不会作为表达式执行。秘密值先脱敏，因此以原秘密为关键词无法匹配。

日志按纯文本渲染，并清除 ANSI/控制字符。未终止行等到完整换行后才显示；断线时丢弃最后一个不完整行。轮换后跟随新文件，不读取滚动备份。

## 安全与限额

API 只接受绑定 ID 和枚举来源，不接受路径、命令、通配符、SSH 参数或服务名。来源映射、部署目标和文件路径由服务器推导；Worker 使用 B12 的公钥固定 SSH 通道读取，拒绝软链接目录/文件及非普通文件。

Worker 复用 [B14 脱敏](./environment-variables.md)，使用本项目所有当前环境的秘密快照，先脱敏再保存和发送；不会通过 API 返回主机密钥、密文或主加密密钥。历史中已删除或替换的秘密、任意编码/变形、恶意主机主动泄密仍可能无法识别；更改秘密后应停止旧会话并重新开始。原始日志的保密责任仍在主机运维方。

- 单次最多读取/传输 1 MiB，单行最多 64 KiB；短时数据库缓冲最多 1 MiB / 10000 块，每块 16 KiB。超限会停止，筛掉的行也计入读取预算。
- 会话最多 60 秒（含排队）；到期后缓冲保留 10 分钟，Worker 每秒清理。Worker 离线时物理清理延迟，API 仍拒绝过期数据。
- 同用户最多 2、项目最多 4、相同 SSH host+port 最多 4、全局最多 100 个活跃会话。DNS 别名不合并计算；Worker 还有独立执行并发限制，繁忙时排队也消耗会话时间。
- 每身份每分钟最多新建 12 次会话、120 次取票/REST读取/取消；429 表示达到频率或并发限制。
- SSE 使用与构建/部署日志相同的 log/status/end/stream-error 协议、短期一次性票据及有序回放；取票、兑换、持续连接均复查权限。凭证不进入持久浏览器状态。反向代理须关闭 SSE 缓冲/缓存，并在访问日志中移除查询参数。

每个会话只允许其发起成员读取。断连会取消会话；API 失联后活跃租约约 5 秒到期，Worker 约 500ms 检查。SSH 远端另有 65 秒 timeout + 2 秒强制终止宽限。本地进程强杀、网络分区或主机故障时无法保证即时回收远端进程；不会宣称完全没有孤儿进程。高吞吐、轮换/截断及重连可能丢行，不保证完整日志交付。

## API 与排障

基础路径：`/api/v1/projects/:projectId/runtime-log-sessions`。

- `POST`：JSON `{ "domainId": "绑定 UUID", "source": "caddy-access", "lines": 200, "level": "all", "windowMinutes": 0, "keyword": "" }` 创建会话。
- `GET /:sessionId`、`GET /:sessionId/logs?seq=0&limit=500`：状态及已脱敏缓冲，limit 最大 1000。
- `POST /:sessionId/log-stream-ticket`：带 Bearer 换取一次性票据。
- `GET /:sessionId/logs/stream?ticket=...&after=0`：SSE，Last-Event-ID 优先于 after；票据最长 60 秒、仅一次使用。
- `DELETE /:sessionId`：结束本人成员会话。

404 也可能是跨项目/其他成员会话，或缓冲已过期。409 表示尚无可用部署或域名验证。503 通常表示 Redis/Worker/主密钥配置未就绪。`ssh_host_key_mismatch` 须通过可信渠道重新核对公钥，不能关闭 pin；`ssh_auth_failed` 须检查专用用户与密钥。`runtime_read_failed` 时检查日志配置已升级、文件存在且部署用户可读、Python3/timeout 可用；没有日志不会回退读取主机共享日志。`runtime_session_expired` / `runtime_session_closed` 表示会话或租约结束，可创建新会话。

本次不提供 journald、docker logs、Node 动态服务日志、第三方日志平台、全文搜索集群、告警或未脱敏原始日志下载。设计详见 [ADR-0014](../adr/0014-online-runtime-logs.md)。英文指南尚未翻译，公开发布前须补齐。
