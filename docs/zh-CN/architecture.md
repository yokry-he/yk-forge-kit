# 架构方向与待决策事项

## 已确认

- ForgeKit 是独立的新项目，SiteForge 仅作为视觉与交互参考。
- 产品入口规划为 Web 控制台、CLI、桌面客户端，分阶段交付。
- Web 前端以 Vue 3 + TypeScript 生态为优先路线。
- 支持 Web/H5、移动 App、小程序、桌面端项目与多云部署，但不承诺单一 UI 代码完美兼容所有端。
- 采用混合资产体系：基础组件/SDK 可发布为依赖包，业务能力以可修改源码集成。
- 公共 UI 组件独立于 ForgeKit 业务项目，拟使用 `yk-forge-ui` 仓库。
- 以成熟稳定、低耦合、适度抽象、可测试及可替换为基础约束。

## 尚未定案

- Web 控制台采用 Nuxt 还是 Vue + Vite。
- API 后端框架、持久化及队列选型。
- 移动端与小程序适配框架的最终组合。
- UI 组件库的包布局、发布渠道及多端范围。
- CLI/核心 SDK/Runner 的内部边界。
- 认证方案、租户隔离模型、云部署适配层及成本模型。

以上事项应通过需求约束、验证原型及 ADR 决定，避免把初步讨论当成实现承诺。
