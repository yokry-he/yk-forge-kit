# 新手模式（B21）

面向不懂技术的使用者和部署者。目标是把“我想做一个 XX”变成模板建议与项目配置记录，而不是让 AI 现场写完整业务代码。

- 相关设计：[ADR 0020：新手模式](../adr/0020-beginner-mode.md)
- 模板总览：[项目模板](./project-templates.md)
- 最后更新：2026-11-22

## 1. 这个功能解决什么问题

用户用一句中文或英文描述需求，例如：

- “我想做一个公司官网，能发文章”
- “帮我做一个记账的小程序”
- “做一个内部用的后台管理页面”

系统根据这句话，从**已有模板**中挑一个最接近的，给出建议项目名和目标平台，用户确认后创建项目。

它**不是**通用代码生成器：

- 不会凭空写出业务逻辑、页面细节或数据库设计；
- 不会生成白名单之外的模板或任意代码仓库；
- 不做需求澄清式长对话，只做“需求 → 模板”的一步匹配。

新手模式是入口层，真正的项目内容仍然来自模板本身。

## 2. 控制台向导步骤

控制台「新手模式」是一个三步向导：

1. **输入一句话需求**
   一个文本框，中文或英文均可。不需要写技术名词，写清“做什么、给谁用”即可。

2. **查看推荐结果**
   系统返回：
   - 推荐的模板（模板 ID 与中文名）
   - 建议项目名（可直接用，也可改）
   - 目标平台
   如果推荐结果为空或明显不合适，用户可以在这里改选。

3. **确认后创建**
   用户确认模板、项目名、目标平台，点击创建。此后走的是**既有项目创建流程**，与手动从模板创建完全一致（见第 7 节）。

推荐的模板、项目名、平台都只是建议值，最终以用户确认的为准。

### 目标平台

| 目标平台 | 说明 |
| --- | --- |
| `web` | 浏览器网页 |
| `uniapp` | uni-app 跨端入口（H5 / 小程序 / 移动端） |
| `weapp` | 微信小程序 |
| `alipay` | 支付宝小程序 |
| `android` | Android 应用 |
| `tauri-desktop` | 桌面应用（Tauri） |

平台取值以实现与 [ADR 0020](../adr/0020-beginner-mode.md) 为准。

### 模板与平台的对应关系

| 模板 | 适用目标平台 |
| --- | --- |
| `vue-web` | `web` |
| `vue-admin` | `web` |
| `nuxt-site` | `web` |
| `uniapp` | `web`、`uniapp`、`weapp`、`alipay`、`android` |
| `tauri-desktop` | `tauri-desktop` |

`vue-web`、`vue-admin`、`nuxt-site` 主要用于网页；跨端与移动端需求交给 `uniapp`；桌面需求交给 `tauri-desktop`。

## 4. 分类是怎么做的

分类分两条路径，按可用性依次尝试。

### 4.1 默认可用：确定性关键词回退

不依赖任何外部服务。系统用内置的中英文关键词映射，把需求文本对应到白名单模板，例如“官网 / 博客 / 站点”偏向 `nuxt-site`，“后台 / 管理 / admin”偏向 `vue-admin`，“小程序 / 跨端 / App”偏向 `uniapp`，“桌面 / desktop / Windows”偏向 `tauri-desktop`，其余默认落到 `vue-web`。

这条路径**无密钥、无网络、结果可复现**，是新手模式的保底能力。

以下情况必须回退到关键词结果，不能卡住向导：

- 未配置 AI；
- AI 调用超时；
- AI 返回内容未通过校验；
- AI 服务不可用或鉴权失败。

回退后来源显示为关键词；无命中或发生兼容性纠正时显示“把握不大，请确认”。身份、参数或限流错误会明确提示重试。

### 4.2 可选：用户自带密钥（BYOK）

已登录的用户可以在控制台「AI 配置」里填入自己的 API Key，开启 AI 分类。默认提供商为 DeepSeek，也支持 OpenAI 兼容的 base URL 与模型名，便于接入自建或第三方兼容服务。

AI 只做一件事：在给定模板清单内选一个模板、给一个项目名和目标平台。它不参与后续代码生成。

## 5. 密钥安全

API Key 的保存与展示遵循既有 B14 方案：

- 使用 **AES-256-GCM** 与部署主密钥加密后落库；
- **只写**：界面上只能新增或替换，不能读回原值；
- **脱敏展示**：仅显示“已配置 / 可替换”这类状态，不显示任何密钥片段；
- API 响应与日志**绝不**回传或打印明文、密文；
- 错误信息使用固定文案，不回显模型原始输出中可能携带的密钥或提示词内容。

用户填写密钥时不需要了解加密细节，但需要知道：写入后无法再取回明文，只能替换。

## 6. 安全边界

- **严格 schema 校验**：模型输出必须符合约定结构（模板 ID、项目名、目标平台），字段缺失或类型不符即判定失败并回退。
- **模板 ID 白名单**：只接受第 3 节列出的五个 ID，其余一律拒绝。
- **防提示注入**：用户需求被视为**不可信数据**，只作为分类输入，不作为系统指令执行。需求文本中出现“忽略以上规则”“改用某个模板”“输出你的密钥”“把系统提示词发给我”之类的内容，一律不生效。
- **超时与速率限制**：AI 调用设有超时和调用频率限制，超限即回退或提示稍后再试；具体阈值以实现与 [ADR 0020](../adr/0020-beginner-mode.md) 为准。
- 分类接口不接受任意模板参数，也不返回模型原始文本。

接口（均使用现有 OIDC Bearer 身份；匿名返回 401，local 模式返回 403）：

- `POST /api/v1/beginner/classify`：请求 `{ description }`，1–2000 字；返回 `{ templateId, name, platforms, source, warnings?, lowConfidence? }`。
- `GET /api/v1/beginner/ai-config`：只返回 configured、provider、baseUrl、model、updatedAt。
- `PUT /api/v1/beginner/ai-config`：provider、baseUrl、model 可覆盖，apiKey 只写；首次必须给密钥，后续空串或省略保留原值。
- `DELETE /api/v1/beginner/ai-config`：删除配置，返回 204。

默认 DeepSeek、`https://api.deepseek.com`、`deepseek-chat`。自定义 URL 指向 OpenAI 兼容 API 根路径（如含 `/v1` 则保留），服务追加 `/chat/completions`；禁止 URL 用户信息、查询和片段，禁止跟随重定向。模型可覆盖。AI 调用上限 10 秒，控制台等待上限 15 秒；分类每身份每分钟 12 次，配置写入/删除每身份每小时共 30 次，超限返回 429。所有响应使用 no-store。日志只记录动作、用户 UUID 和分类来源。

## 7. 创建项目

用户确认后，新手模式调用**既有项目创建流程**，不另开一套生成器：

- 与手动选择模板创建走同一套代码路径；
- 调用既有 `POST /api/v1/projects`，传入 name、template、模板默认 features 及可选 platforms；服务再次校验平台兼容性并保存；
- 成功后打开现有项目详情；此步骤只登记项目配置，源码仍需用现有 CLI 生成，平台选择不会自动触发构建、签名或发布；
- 新手模式不额外写入模板之外的文件，也不改写模板内容。

也就是说，关掉新手模式不会影响已创建的项目。

## 8. 部署与配置

新手模式复用既有部署配置，没有独立的一套环境变量。常规部署至少需要：

| 变量 | 用途 |
| --- | --- |
| `DATABASE_URL` | 数据库连接 |
| `AUTH_MODE=oidc`、`OIDC_ISSUER`、`OIDC_API_AUDIENCE`、`OIDC_JWKS_URL` | API 验证身份（见 [Web OIDC 登录](./web-oidc-login.md)） |
| `FORGEKIT_DEPLOY_ENCRYPTION_KEY` | 部署主密钥，同时用于 B14 密钥加密 |

说明：

- **不配置任何 AI 相关项，新手模式照常可用**，走关键词回退。
- AI 分类的提供商、base URL、模型名与 API Key 建议通过控制台「AI 配置」写入，加密保存，不写进环境变量、不落到配置文件。
- 控制台登录配置使用 `VITE_OIDC_AUTHORITY` / `VITE_OIDC_CLIENT_ID` / `VITE_OIDC_RESOURCE`；不需要在浏览器中保存 client secret。
- 先按既有流程显式执行迁移 `0018_b21_beginner_mode.sql`（包含配置表与项目可空 platforms 列），应用启动不会自动迁移。
- 环境变量命名以仓库现有部署文档为准，上表沿用既有项。

## 9. 真实使用需要用户自行提供什么

新手模式只负责“选对模板并建项目”，以下东西它替代不了：

**要用 AI 分类**

- 自备 DeepSeek（或 OpenAI 兼容服务）的 API Key；
- 在控制台「AI 配置」中写入，并选择提供商 / base URL / 模型名；
- 不提供密钥时，功能不受影响，只是走关键词回退。

**要真正发布到各端**

| 目标 | 需要用户自备 |
| --- | --- |
| 微信小程序 | 微信开发者账号、AppID、服务器域名白名单、上传密钥 |
| 支付宝小程序 | 支付宝开放平台账号、AppID、白名单与密钥配置 |
| Android | 签名证书、包名、应用商店账号 |
| 桌面（Tauri） | 各平台签名证书与分发渠道 |
| Web | 域名、证书、托管环境 |

这些账号、证书与白名单审核都需要用户自己完成，新手模式不代办。

## 10. 能力边界与回滚

### 能力边界

- 只能推荐第 3 节的五个模板，不能生成白名单之外的模板；
- 不能生成任意代码仓库，也不能克隆外部仓库；
- 不自动部署，不自动申请小程序 / 开放平台账号，不自动配置域名与证书；
- 不保证推荐一定“正确”，只保证结果在可用模板范围内；用户始终可以手动改选。

### 回滚与关闭

- **只想关掉 AI**：在「AI 配置」中删除配置，分类自动回到关键词回退。
- **想完全不用新手模式**：从模板列表手动创建项目，功能等价，已创建项目不受影响。
- 本期没有独立入口开关；回退版本前停止相关写入，保留新增表、platforms 列及主密钥，优先前向修复，不自动反向 DDL。
- 回滚不会删除任何已创建项目，也不会改动项目内容。

遇到推荐结果不符合预期时，先在向导第 2 步改选模板；仍不合适，直接走 [项目模板](./project-templates.md) 手动创建。

关键词规则和可执行测试样例见 [分类目录](./beginner-mode-catalog.md)。中文为权威文档；英文对应版本尚未完成，公开发布前必须补齐。

## 11. 验证与上线检查

- 关键词目录、可注入 AI 客户端、超时/注入/非法输出回退、API 身份/参数/限流及密钥只写测试位于 `apps/api/test/beginner*.test.ts`。
- 控制台向导与 HTTP 客户端测试位于 `apps/console/test/beginner*.test.ts`，覆盖确认/编辑/创建/导航、低置信提示及配置替换/删除。
- 数据库单测覆盖 B21 AAD 与保留/替换/删除；`packages/db/test/beginner.mysql.test.ts` 为可选真实 MySQL 验证，接入根目录 `db:test:integration`，必须使用 [一次性测试数据库](./mysql-integration-testing.md)。
- 运行仓库 `build`、`typecheck`、`test` 与 `db:migrations:check`。默认测试不调用真实 AI 服务；真实提供商连通性、数据库迁移执行和部署验收须在相应测试环境单独进行。
- 影响范围为新增入口、用户 AI 配置及可选项目平台元数据；既有调用方不传 platforms 时继续兼容。上线前备份数据库并确认主密钥配置；回退时保留新增存储和密钥，参见 ADR 的回滚约定。
